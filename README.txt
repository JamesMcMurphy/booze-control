BOOZE CONTROL - iPHONE WEB APP / PWA

This is a standalone web-app version designed to be added to an iPhone Home Screen.
It does NOT require the Apple App Store or a $99 Apple Developer membership.

Features included:
- Staged drinks
- Tap staged drink bubbles to remove one
- Other Drink above Quick Add
- Quick Add: O-Bomb, Bacardi Shot, Suncruiser, Rum & Coke
- Submit Drinks For The Day
- 4 AM tracking-day boundary
- If staged drinks cross the 4 AM boundary, they auto-submit the next time the web app is active/open
- September-December 2026 calendar
- Martini markers
- Tap calendar dates to view and remove drinks
- Local persistent storage on that iPhone
- Animated colorful background
- Home Screen / standalone PWA support
- Offline cache after first load

HOSTING (GitHub Pages - free):
1. Create a GitHub repository, for example booze-control.
2. Upload EVERYTHING in this BoozeControl_PWA folder to the repository root.
3. GitHub repository -> Settings -> Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Pick the main branch and root folder, then Save.
6. Wait for GitHub to give you the https://...github.io/... address.

IPHONE INSTALL:
1. Open that HTTPS address in SAFARI on your girlfriend's iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on Open as Web App.
5. Tap Add.
6. Booze Control now appears on the Home Screen and opens like an app.

IMPORTANT DATA NOTE:
Drink history lives locally in Safari storage on that iPhone. It stays across normal launches, but clearing Safari website data can delete it. A future upgrade could add cloud backup/sync.
